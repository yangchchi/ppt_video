# 数字人布局与比例

## 目标

数字人区块增加布局（左/中/右）、比例（30%–150%）与预览示意。去掉「中间布局」模板。

## 规则

- 无数字人：隐藏布局、比例、预览
- 模板 `none`：可调布局与比例，默认布局右、默认比例 40%
- 模板 `left` / `right`：布局锁定为模板侧，只调比例，默认 100%
- 模板仅保留 `none` / `left` / `right`；`center` → `none`

## 字段

- `avatarCorner`: `left` | `center` | `right`
- `avatarScale`: `0.3`–`1.5`

## 合成

- 有模板槽：按槽位贴对应侧/中，尺寸 = 槽 × scale
- 无模板：按 `avatarCorner` 生成基准槽再缩放贴底
