# 功能规格：PPT 转视频

## 1. 目标

用户在网页上传一份 `.pptx`。系统先读出每一页的页面文字和备注，让用户选定旁白来源、音色、语调、时长、画幅和转场，再生成视频。画面是该页幻灯片，旁白是用户确认后的脚本。全部页面按原顺序接成一个 MP4，供在线播放和下载。

交互参照 [Leadde](https://leadde.ai/) 的幻灯片导入：先看到文件和选项，确认后再开始生成。数字人和模板市场用本地轻量目录，不接云端形象、口型、积分或大模型。

## 2. 用户

本地使用的单人。不登录，不区分账号。

## 3. 范围内

- 网页上传 `.pptx` 后进入配置，而不是立刻渲染。
- 配置项：导入方式、脚本来源、语言与音色、语调、视频时长、画幅、转场、背景音乐、重点高亮。
- 脚本来源三种：使用备注、根据页面文字、无旁白。
- 导入方式两种：静态导入直接采用所选来源；逐页脚本可在生成前改每一页旁白，并按当前选项重写。
- 根据页面文字时，可填写目标受众、演讲者、学习目标。这些文字只写进第一页或最后一页旁白，不调用外部模型。
- 生成前可试听当前音色、语调和时长对应的一句样例。
- 页与页之间使用用户选择的转场，默认淡入淡出。
- 画幅三种：全幅页面、舞台画框、缓慢推镜。选用模板后，版式以模板为准。
- 公共模板按行业浏览：推荐、教育、培训、软件、金融、医疗、制造业。模板决定背景色、幻灯片区域和数字人位置。
- 数字人是本地半身肖像，可选男性、女性，或不要数字人。贴在画面左下角或右下角，不悬在中间。每个人有闭嘴和讲话两张图，有旁白时按音量切换，没有声音时用闭嘴图。不对云端口型，也不换装。
- 「我的模板」把当前公共模板和数字人的组合存在这台浏览器里，可再次套用或删除。不上传、不共享。
- 可选一条本地合成的轻柔垫底音乐，音量低于旁白。
- 处理过程中展示当前步骤。成功后播放、下载，并展示每页脚本摘要。
- 首页提供「生成历史」。历史页列出已生成的视频，点击一条即可播放和下载。服务重启后历史仍在。未开始生成的配置稿重启后仍可继续配置。

## 4. 范围外

- 不支持旧版 `.ppt`、Keynote、PDF 直接上传。
- 不在画面上拖拽、改字或替换幻灯片元素。
- 数字人不用云端驱动，也不上传自己的底图。模板不能改坐标。
- 不把文件送到外部大模型改写脚本。
- 不提供多用户、队列仪表盘、积分或云存储。
- 不保证与 PowerPoint 动画、嵌入视频、自动播放音频一致。导出的是静态页面，缓慢推镜只在成片上增加位移。

## 5. 主流程

1. 用户打开首页，选择或拖入一个 `.pptx`。
2. 系统校验扩展名、大小和演示文稿包，创建配置稿，显示文件名、页数和大小。
3. 用户选择导入方式、脚本来源和其他成片选项。逐页脚本模式下可以修改每一页旁白。
4. 用户点击生成。若已有任务在排队或处理，按钮不可用。
5. 页面轮询任务状态，依次显示：校验、导出画面、合成语音、拼接视频。
6. 成功后页面播放视频，并提供下载。每页显示序号和脚本摘要。
7. 失败后页面显示中文原因。配置稿在生成开始前可以移除并重新上传。

同一时间只渲染一个任务。配置稿不占用渲染队列。

## 6. 画面规则

- 每一页对应视频中的一段，顺序与 PPT 页序一致。
- 全幅页面：画面宽 1920，高等比，不足处以白边补到 1920×1080。
- 舞台画框：同一页放大虚化后作为背景，幻灯片缩小后居中。
- 缓慢推镜：全幅页面上镜头从 1 倍缓慢推到约 1.05 倍。字幕仍烧在每一行对应的画面上，推镜按该行时长单独计算。选用模板时不使用这三种画幅。
- 未选模板且选了数字人时，肖像贴在画面右下角，下缘对齐画面底边，避免半身悬在中间。
- 选了模板时，幻灯片缩进模板给出的区域。数字人贴在槽位所在的左下角或右下角，下缘对齐画面底边。模板没有槽位时不叠肖像。
- 有旁白且音量起来时换成讲话图，音量落下后换回闭嘴图。
- 该段时长等于该页旁白时长。
- 脚本为空或只有空白时，该页无旁白。停留时间由视频时长决定：简短 2 秒，自动为 `EMPTY_SLIDE_SECONDS`（默认 3 秒），充分为 5 秒。

## 7. 语音与脚本规则

- 使用备注：文案为该页备注中占位符类型为正文（body）的文字。段落之间保留换行。不朗读幻灯片缩略图、页码或其他占位符。若备注页没有正文占位符，则使用备注页中的全部文字。
- 根据页面文字：朗读标题和正文要点。占位符为页码、日期、页脚、页眉的文字不进入旁白。第一页可带演讲者和目标受众各一句，最后一页可带学习目标一句。没有页面文字时，这一页按空脚本处理。
- 无旁白：每一页脚本都为空。
- 静态导入在点击生成时按当时的来源和补充说明写入脚本。逐页脚本使用用户提交的文本；每页不超过 4000 字。
- 补充说明每项不超过 80 字。
- 页面先选语言（普通话、粤语、英语），再选该语言下的音色。默认晓晓（`zh-CN-XiaoxiaoNeural`）。未选择时也可由环境变量 `TTS_VOICE` 指定默认音色，该音色必须在可选列表中。
- 语调改变音高和基础语速：正式稍慢稍低，平稳不变，生动稍快稍高。
- 视频时长在语调之外再调整语速：简短更快，自动不变，充分更慢。合并后的语速限制在 -40% 到 +40%。
- 页面可选转场：直接切换、淡入淡出、向左滑入、擦除、圆形展开。默认淡入淡出，时长 0.5 秒。某一页短于转场所需时间时，这一处改为直接切换。
- 有脚本的页面在画面底部显示白色字幕，不铺背景色，并且同一时刻只显示一行。这一行的语音结束后，才切换到下一行。无脚本的页面不加字幕。
- 重点高亮默认打开。某一行字幕对上页面上某个文字形状时，这一行画面给该形状描一圈圆角框。对不上、关掉开关、没有位置、或形状在组合、图表、表格里时不画框。
- 每一行字幕的画面时长与该行语音时长一致，整页画面总时长与该页音频时长一致，偏差不超过一帧。
- 单页脚本超过 500 字时按句号、问号、叹号、换行切段，分别合成后再接成这一页的旁白。
- 背景音乐打开时，成片混入循环的本地垫底和声，不盖过旁白。关闭时成片只有旁白或静音。
- 试听使用固定短句，不消耗配置稿。普通话和粤语试听中文短句，英语试听英文短句。
- 语音需要访问微软 Edge 在线朗读服务。无网络时任务或试听失败。

## 8. 限制

| 项 | 值 |
| --- | --- |
| 格式 | 仅 `.pptx` |
| 大小 | 最大 50 MB，可用 `MAX_UPLOAD_MB` 调整 |
| 页数 | 最多 80 页 |
| 补充说明 | 每项最多 80 字 |
| 单页脚本 | 最多 4000 字 |
| 空脚本停留 | 简短 2 秒，自动默认 3 秒，充分 5 秒 |
| 输出 | H.264 + AAC 的 MP4，1920×1080 |

## 9. 失败时用户看到的结果

渲染开始后失败，不提供半成品视频。页面保留失败原因，例如：

- 文件不是 `.pptx`，或不是有效的演示文稿包。
- 文件超过大小或页数限制。
- 选项、补充说明或某一页脚本无效。
- 已有任务在处理。
- 本机没有 Microsoft PowerPoint，或 PowerPoint 导出 PDF 失败。
- 导出的 PDF 页数与幻灯片页数不一致。
- 语音合成失败（含网络不可用）。
- 本机没有 ffmpeg，或视频拼接失败。

配置稿还没开始渲染时，校验失败不会留下任务。

## 10. 验收

用一份至少两页的 `.pptx`：第一页有中文备注和标题，第二页备注为空但页面上有标题。

- 上传后先出现文件信息和选项，此时还没有视频。
- 使用备注并静态导入：第一页能听到与备注一致的中文旁白；第二页无旁白，自动时长下画面约 3 秒。
- 改成根据页面文字：旁白来自标题和要点，而不是备注。
- 逐页脚本里改掉第一页文字后，成片朗读改后的文字。
- 备注和页面文字都不出现在幻灯片画面以外的新文本框里；字幕只来自最终脚本。
- 打开背景音乐时，成片能听到垫底音乐，旁白仍可辨认。
- 首页能完成配置、看到进度、播放并下载 MP4。
